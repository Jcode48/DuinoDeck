# DuinoDeck
DuinoDeck is an Arduino StreamDeck project. its made with an Arduino Uno with 2.8 inch TFT screen shield and some python. 
It works by detecting if you tap a button, sending it via serial to the computer and a python script executes what you want. It has a graphical interface to change the buttons.

# What you need:
- Arduino Uno
- 2.8 inch TFT shield
- Computer

# How to set it up:
first you download the latest exe and the source code (YES YOU NEED THE SOURCE CODE). Then you upload the ino file from the source code to your Arduino, slap on the shield and run the exe. You find the right port and hit connect, then you change it how you want and you sync it. This wil create a json file so your settings don't get wiped when you close the program. If you press the minimalize button it will minimize to your tray.
